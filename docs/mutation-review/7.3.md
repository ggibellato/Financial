# 7.3 CashFlow.Infrastructure (80.6% → 91.1%)

Files: the whole project. The biggest gap was the reference map in `CashFlowTypeInfoResolver`:
the serializer tests load and save with the same resolver, so a wire name or a "must be present"
flag could change and every file would still round-trip. Timeouts are counted as detected.

Gaps closed:

- **`CashFlowTypeInfoResolver`**: each reference property is written under its wire name and is
  required only when every existing record has the key (one theory, 17 cases, mirroring the
  table on purpose: it is the data file's contract).
- **`CalendarConnectionStore`**: the credentials are saved at the configured path (the round-trip
  test passed even when every save went to the default path), into a folder created if missing,
  and a null connection is rejected.
- **DI**: the Google Calendar settings are bound from configuration, and the CashFlow
  infrastructure registers the system clock on its own (the test container's FxRate
  registration hid it).
- **`CashFlowDataConverter`**: a `null` collection in the file loads as empty.
- **`ReferenceConverter`**: reading without a lookup throws (one test per converter).
- **`CashFlowJsonRepository.Load`** rejects a null storage or serializer.

Removed: `CashFlowJsonRepositoryTests.Constructor_WithNullData_Throws`, covered by
`ConstructorGuardTests`, which checks every public constructor's null arguments.

The 22 still undetected, all reviewed:

- **`ConfigureAwait`** (8).
- **Wording** (2): `WriteIndented` in the credentials file, and the no-lookup exception message.
- **Equivalent** (4): the loader's `catch (FileNotFoundException)` block (Stryker's removal returns
  `default`, which is the same null); `Refusal`'s `<` vs `<=` (equal versions return earlier);
  `_lastPersistedJson ?? Serialize(_data)` (re-serializing the loaded data gives the same
  document); `Load`'s serializer guard (the constructor throws the same `ArgumentNullException`).
- **Unreachable** (4), production notes: `CashFlowDataConverter`'s `JsonConverter.Read` override
  (the serializer calls the static `Read(root)`); `ReferenceConverter`'s null-token branch
  (System.Text.Json never calls a reference-type converter for `null` unless it sets
  `HandleNull`); the "no reference converter registered" throw (2: every mapped property type has
  one).
- **Accepted** (4): relative versus rooted credentials paths (2: the test runner's working
  directory is the base directory, so both resolve to the same file); the null guards on
  `CashFlowDataFileVersion.StoredIn(JsonObject)` and `Stamp` (2).
