## Gaps closed (41 test cases)

- **Account transfers**: an edited counterpart that is still listed is not listed twice; editing a
  transfer out of the account opens on its destination with the amount received; a transfer in
  one currency opens with no amount received; the remembered counterpart is used only for its own
  direction and only while listed; whitespace dates, zero amounts and zero amounts received are
  refused, with the first message in the banner; the saving flag, the fallback message, a
  whitespace note sent as none, and the date remembered after a save.
- **Mensais**: the saving, adding and resetting flags clear when a save, add or reset settles; an
  open expense prompt stays open when another bill's status changes; a load error from an earlier
  request is ignored once a later one has loaded; the load fallback message; whitespace status
  and description, and a value that is not a number, are refused; an edit saves the bill being
  edited, not the first one listed; a UK bill moved to a status other than Paid, or set to Paid
  when already Paid, is updated without the prompt.
- **Income form**: the gross value is kept across sources that report one and cleared for one
  that does not; an income opens with blank gross value, bank and description when it has none,
  and with its gross value when it has one; cancel leaves edit mode; the saving flag clears after
  a save, a kept-open save and a failure; a negative net value is refused; a pots deposit opens on
  the source of that pots account, else the first source that splits, else none; the remembered
  source is used only while listed; a chosen pots account survives unticking and ticking the
  split, and the source's account is filled only when the split is ticked with none chosen; an
  unticked split saves with no pots account; whitespace date and source are refused (first
  message in the banner) and a whitespace gross value is sent as none; the funding names the chosen
  bank and the bank an edited income opened on; on a bank screen the default line has no amount
  until there is a net value.

The existing "does not remember the locked bank" test now locks a bank that is in the bank list,
so remembering it would show.
