Files: the whole project (579 lines). Most of the gap was code with no test in its own project:
the telemetry span helpers were covered only through every service's span assertions, and
`ReflectionJsonTypeInfoHelpers` only through the CashFlow and Investment JSON resolver tests.

Gaps closed:

- **Telemetry helpers**: `StartServiceSpan` names the span `{context}.{service}.{operation}` and
  sets exactly the bounded context, entity type and operation attributes; `MarkSuccess` and
  `MarkFailed` set the result, and `MarkFailed` records the same exception.
- **`ReflectionJsonTypeInfoHelpers`**: a type with a private constructor and private setters
  deserialises, with JSON names matched case-insensitively and a read-only property skipped; a
  factory that is already set is kept (found by the simplify review: the first version of this
  test went through a public constructor and so passed with the guard removed).
- **`EnumParser`** ignores case and rejects unknown names.
- **Null arguments**: `JsonRepositorySettings.Load` and `JsonStorageFactoryExtensions.Create`
  throw for each null argument, before creating any storage (without the guard, a null
  configuration key would go unnoticed for local JSON).

Removed: `InMemoryCachedExchangeRateProviderTests.Constructor_NullInnerFactory_Throws`, a weaker copy
of what `ConstructorGuardTests` already checks for that constructor.
