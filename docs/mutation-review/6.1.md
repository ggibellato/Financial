## How it was measured

Two Stryker runs, because utils reach almost every test:

- **Run A**: every util except the two focus helpers, against `src/utils/__tests__` plus the tests
  that import the eight small utils with no unit test of their own (59 test files).
- **Run B**: `focus` and `retryOutcomeFocus`, which about 60 tests import each, against those
  tests and `src/utils/__tests__` (103 test files).

Both runs are "before" runs. Every surviving mutant was then replayed by hand: the replacement
from the report applied to the source and the util's own test file run against it (the importing
tests for a util with none). Before any test was added, the replay killed 12 of the reported
survivors: module-level constants (number formats, the month pattern, two network messages and the
two focus selectors) are built when the module first loads, before Stryker switches a mutant on, so
the run cannot see what the tests already catch. The before figures above are Stryker's and count
those 12 as survivors; the after figures come from the replay with the new tests, so 12 of the 87
mutants gained were already caught and 75 are the new tests' work.

## Gaps closed (53 test cases)

- **Formatters**: two-to-four-decimal numbers; month values with anything before or after the
  month; an empty UTC date; the MM/yyyy month key; the green and red sign classes, zero included;
  blank text and the minimum and maximum of a validated number.
- **Field errors**: an empty message is skipped and the one read is trimmed; a field is named by the
  element that labels it, by its trimmed label, or by its `aria-label`.
- **Funding lines** (adding, changing and removing a line had no test): a new line starts empty with
  a key of its own; changing or removing a line touches only that line; an added line holds what
  the others have not covered, and no line is added past the limit.
- **Holding navigation**: a holding under another broker is not found; a null pending selection
  reads as none.
- **Month transaction totals**: currencies in code order and the no-currency bucket last, whatever
  order the rows come in.
- **Selectable banks**: an inactive bank is marked, an active one or one with no flag is not.
- **Tax workbook CSV**: a quote inside a field is doubled and an empty value stays empty; the
  download saves the text as a CSV of the given name and removes its link and object URL.
- **New test files** for utils covered only through their callers, or not at all: lot allocation
  (exact allocation despite floating-point drift, none for a sale of zero, finding the one
  over-allocated lot), movement edit validation (a date or bucket of spaces is missing), currency
  footer items (one currency, none, several), tree node metadata, and retry outcome focus (the
  first control or the region itself is focused, an existing tabindex is kept, content outside the
  region is left alone, and only one outcome claims the focus).

## Still undetected

All reviewed:

- **Equivalent** (23):
  - **Field errors** (4): the empty-id fallback string (no element has those ids) and three
    optional chains on `textContent`, which is never null on an element.
  - **Funding lines** (1): the line counter counting down (keys stay unique).
  - **Holding navigation** (5): the node type checks for brokers, portfolios and assets (the tree
    holds only those, in that order), and the object checks that a string state passes (reading a
    property of a string gives nothing).
  - **Lot allocation** (3): the two tolerance boundaries (no floating-point difference lands exactly
    on the tolerance) and the fallback for a lot with no allocation (it parses to nothing either
    way).
  - **Month transaction totals** (2): the two halves of the no-currency ordering, equivalent on V8
    only, as in [5.10](5.10.md): V8 always passes the row being placed first.
  - **Tax workbook CSV** (2): an `undefined` field (the API sends `null`) and the currency fallback
    for a jurisdiction other than BR or UK (the type allows none).
  - **Period filter** (1) and **upcoming income window** (1): an early return whose case the code
    after it also returns.
  - **Focus** (1): `activeElement` null (the document always has a body).
  - **Retry outcome focus** (3): the `once` option of the focus listener (stopping is idempotent and
    the same listener is never added twice) and the early return when nothing awaits a retry (the
    claim refuses it anyway).
- **Wording** (3): the missing-value dash, the "Saving…" label, and the label of a field with no
  name at all.
