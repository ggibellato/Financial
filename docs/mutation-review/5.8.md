## Gaps closed (12 test cases)

- **Investment snapshots**: the edit stays open and marked as saving while the value is sent, and
  closes with the value cleared once saved; a failed save is no longer shown as saving; a value that
  is not a number marks the field; cancel drops the edit and its messages; retry loads again after a
  failed load; an older month that fails after the newer month loaded is ignored.
- **Asset summary**: loading ends once the asset, its load error or its price error arrives; a node
  that is not an asset clears the asset; retry loads the asset again; a cryptocurrency with no
  exchange is priced with an empty exchange; an equity with no exchange is not priced. The historic
  portfolio weight test now lists another asset first, with its own weight, so the weight read is
  the selected asset's.
- **Portfolio summary**: a failed load ends the loading state; the rows start with nothing failed
  and nothing manual, and a failed row is not marked manual; a row price failing after another row
  succeeded leaves that row alone; the valuation of a portfolio left while its prices were loading
  is not read again.
- **Disposals**: another asset starts from all tax years with nothing expanded; all chains are
  listed until a tax year is chosen. The grouping test now has two earlier records, given out of
  order, so the history leaves out the active record and is sorted newest first.
- **Price history**: deleting one entry keeps the form open on another; a second delete waits for
  the first; a date of spaces is refused as missing; a transaction at midnight on the first day of
  the window is kept.

## Still undetected

The last Stryker run was the before run, so the new tests were checked by hand: each mutation was
applied to the source and the hook's test file run against it. 34 of the 35 mutants checked are
killed; the one left is the snapshot retry counter, counted as equivalent below. What is left, all
reviewed:

- **Equivalent** (26):
  - **Callback and effect dependencies** (16): `useCallback` arrays that gain a constant or lose a
    dependency that never changes (the dispatchers and the request guards are stable), across all
    five hooks.
  - **Retry counters** (4): counting down instead of up still changes the count, which is what
    starts the reload.
  - **Asset summary** (5): the ticker check in the price arguments (both callers check it first);
    the node type check (only asset nodes carry an asset name); the "not an asset or no node"
    condition (the next check resets the same nodes); the optional chaining on the ticker (only
    reached for an asset); the empty `catch` on the portfolio weight (the weight is already null
    while loading).
  - **Disposals** (1): the dependency of `retry` on the resource's own retry, which never changes.
- **Wording** (9): the load, save and delete fallback messages (snapshots 2, asset summary 2,
  portfolio summary 1, disposals 1, price history 3).
- **Accepted** (1): the price history entries on the first day of the window. A price date has no
  time, so it is read as midnight UTC and compared with local midnight; the boundary only meets at
  a UTC offset of zero, so a test for it would depend on the machine's time zone. Transactions carry
  a time and the same boundary is tested on them.
