Files: the whole project (799 lines). Most of the gap was in `DebouncedJsonStorage` (the debounced
save cycle shared by every Google Drive repository): its flush and failure paths. Timeouts are
counted as detected.

Gaps closed:

- **`DebouncedJsonStorage`**:
  - A flush cancels the pending debounce, so the document is saved once, not again when the
    timer fires.
  - A write after a flush is not saved early by the debounce timer the flush cancelled (the
    generation counter must never come back to a value a stale timer holds; found by the second
    simplify review, which showed the `++` vs `--` mutants were not equivalent).
  - A flush during an in-flight save waits for that save, with or without a newer write, and
    never starts a second, concurrent one; a newer document stays pending.
  - A write after a failed save starts a new save (the failure clears the in-flight flag).
  - A failed read rethrows and records a failed `JsonStorage.Load` span.
- **`RemoteJsonStorage`**: a failed upload records a failed `RemoteStorage.Upload` span.
- **`RemoteStorageFactory`**: a configured credentials file that does not exist throws
  `FileNotFoundException` naming that file.
- **`FxRateSerializerAdapter`** writes `storedAt` in the ISO round-trip format and rejects null
  rates; **`FxRateJsonStore.SetRateAsync`** rejects a null record.

Removed:

- `LocalJsonStorageTests.WriteAsync_WritesContentToFile`: the shorter-content test writes and
  reads back the same way and also proves the old tail is gone.
- `DebouncedJsonStorageTests.ReadAsync_PassesThroughToWrappedStorage`: folded into the load-span
  test, which now also asserts the returned content.

The 26 still undetected, all reviewed:

- **`ConfigureAwait`** (11).
- **Wording** (10): the `Trace.TraceWarning` lines in `FxRateJsonStore` and `FxRateLoader`, and
  exception messages.
- **Equivalent** (5):
  - `++` vs `--` on the follow-up cycle's generation (1): it runs only after a save, when no
    earlier debounce timer can still match.
  - The clean-flush early return (1): falling through awaits an already-completed task.
  - Awaiting the completed cycle (1): `SaveNowAsync` catches everything, so the task never faults.
  - The retry delegate's `true` (1): the result is unused.
  - `LocalJsonStorage`'s own `FileNotFoundException` (1): `File.ReadAllText` throws the same type.

Test-environment note: a mutant in `LocalJsonStorage`'s default path can leave a `data.json` in the
test project's `bin` folder, which then fails `Constructor_WithNullPath_UsesDefaultFileName` on
the next plain test run. Delete it after a Stryker run.
