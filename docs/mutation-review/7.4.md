Files: the whole project. Timeouts are counted as detected.

Gaps closed:

- **Currency backfill on load** (a false pass): the test for "a transaction or credit with no
  currency takes its broker's" used a BRL broker, and `BRL` is `Currency`'s default value, so it
  passed with the backfill removed (checked by hand). It now uses GBP and covers historic brokers
  as well as active ones. The currency round-trip test had the same flaw (BRL in and BRL out) and
  now uses USD (found by the simplify review).
- **Yahoo Finance**: each exchange maps to its symbol suffix (`BBAS3.SA`, `VOD.L`, none for NYSE
  and NASDAQ, case-insensitive), and requests carry a browser user agent.
- **Price fetchers**: the standard fetcher asks the finance service for the exchange and ticker,
  and the crypto fetcher for the broker's currency and the ticker. The existing tests only
  checked the returned snapshot (the crypto one is named "...WithResolvedCurrency"); the test stub
  now records the request.
- **DI**: one price fetcher per quote source (standard, crypto, bond), the price service and the
  dividend and snapshot sources are registered, and the infrastructure registers the system clock
  on its own.
- **`PriceQuoteOptions`**: a zero duration is accepted (only negative ones are refused), and a
  null reader is rejected; **`CachingFinanceService`** rejects a null request.
