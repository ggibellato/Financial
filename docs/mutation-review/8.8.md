## Gaps closed (45 test cases added, 11 extended)

- **Ticker picker** (11 added): it starts closed; only the current value is selected and only the
  active option is active; Enter chooses the first option; keys other than Enter choose nothing;
  the keys it handles do not scroll or submit, and a mousedown on an option does not take focus
  from the input; the active option is scrolled into view; with no tickers the arrow keys open an
  empty list without failing; typing opens it; a click inside keeps it open; it reopens with no
  active option after a choice, Escape or a click outside; new tickers and a new handler are used
  once they change, by mouse and by keyboard.
- **Shares dividend check** (11 added, 1 extended): the watchlist is offered under its groups; a
  ticker typed before the watchlist arrives is kept; an empty watchlist loads without failing and
  offers nothing (the mutants that read its first item are caught by the error they throw, not by
  an assertion); the ticker is trimmed as well as uppercased; a blank ticker asks for one and
  checks nothing; a later success clears the error; a failure without a reason is named; checking
  does not reload the page; history sorts by Type and Value and year totals by Total, each header
  marked; a price equal to the max buy is not below it; no history and no annual totals are said;
  the placeholder goes once there is a result or an error.
- **Current values** (10 added, 1 extended): Loading shows while the brokers load and again on
  retry, and only the heading and button show before a check; a failed load without a reason is
  named; each portfolio in scope is read from its own broker; an asset with no exchange is skipped;
  with nothing to check nothing runs; the progress bar moves by each finished asset and starts from
  zero on the next check; a result is named by the looked-up name, else the asset name; results
  sort by Ticker and Name, and every header (Price included) is marked; focus stays on a result
  when later results re-sort the rows.
- **Account header** (5 added, 1 extended): the summary is dimmed while busy and plain otherwise;
  a bank balance is not top-aligned and a card's statement figure is; the statement status sits
  in its own element; the account shown is the selected picker option; accounts passed in later
  are listed.
- **Sidebar** (4 added, 5 extended): a single divider sets Admin apart; the rail and a category
  header carry no extra class when inactive; the flyout id is named after its category; after
  Escape returns focus, the next hover opens the flyout again; keys other than Escape keep it
  open; the toggle's label and tooltip follow its state; on a phone only the current category is
  marked and Escape reports closing.
- **Investment account dialog** (3 added, 3 extended): no other inactive card is offered when the
  linked card is inactive; Cancel closes without asking once a chosen Pots account and source are
  undone; switching Active off submits it; a failed save without a reason is named; a chosen Pots
  account, or no Pots account to choose, shows no "Select a Pots account."
- **Aggregated summary** (1 added): each signed figure, native and converted, is green when gained,
  red when lost and plain when missing.

## Still undetected

All reviewed:

- **Equivalent** (13):
  - Stable dependency lists (4): `loadData` and the watchlist load depend on nothing, and the two
    lists that name `loadData` see the same function every render, so an empty or changed list
    runs them the same.
  - The Sidebar's `cancelClose` in `scheduleClose` and `closeNow` (2): every pointer leave follows
    an enter, and every open cancels the timer; `open` returns early only on the suppress flag,
    which the focus it follows clears at once. No timer is left to close an open flyout.
  - The ticker picker's scroll guard (1): with no active option, `items[-1]?.` does nothing either
    way.
  - The current values error clears (2): the error starts empty and a retry clears it before
    loading, so the load clearing it again changes nothing, and while retrying the page shows
    Loading.
  - The fetch failure message (1): it is stored on the result but never shown (see Noticed).
  - The dividend history row key (1): the rows hold only text, so with one shared key React reuses
    them by position and shows the same rows.
  - The max-buy `> 0` check (2): the backend's max buy is never negative, so `currentPrice <
    priceMaxBuy` with a max buy of 0 or less needs a negative price.
- **Accepted** (2): the ticker picker's outside-click listener while closed, and never removing
  it. Both only differ after ArrowUp on a closed list, which makes the first option active without
  opening the list (see Noticed); a test would pin that quirk.

## Noticed

- When one asset's price fetch fails on Read assets current values, its error message is kept on
  the result but never shown: the row only reads "—". Showing the reason (or dropping the field)
  is a small change for its own PR.
- ArrowUp on the closed ticker picker makes its first option active without opening the list, so
  the next open starts with it highlighted. ArrowUp could open the list as ArrowDown does.
- The ticker picker's groups have no accessible grouping (no `role="group"` or label link), so the
  dividend check test finds an option's group through the DOM.
