## Gaps closed (34 test cases added, 6 removed)

- **Portfolio holdings** (25 added, 5 removed):
  - Every sortable header sorts the rows ascending and marks itself as the active sort (18
    headers, the historic-only ones included); none of the sort keys had a test. The three older
    sort tests this table covers are removed, and the remaining ones read the row order through one
    helper. A holding with no credit month sorts last by last month's credits, whatever stale
    amount it carries.
  - A row whose price failed shows a dash in the current value, current price and both profits,
    even with stored figures (the two older "at least five dashes" tests are removed); a manual
    price that is still loading or failed shows no Manual badge.
  - The totals: none without holdings; no "pending prices" footnote while calculating or with no
    price at all (added to the existing tests). The existing totals tests matched patterns such as
    `30[.,]00`, which a subtraction's `-30.00` also matches, so they now compare the exact figure,
    and the pending-total fixture gives the loading row a value so that counting it would show.
  - No table while the holdings reload or fail, even with items from before.
- **Asset summary** (6 added, 1 removed): the ISIN and local type, and None when either is missing;
  the current value and the current value plus credits; a dash under As of for a price with no
  date (replacing an older, looser test); the historic XIRR figures coloured by their own sign. The
  existing result and XIRR colour tests now also check the with-credits figures, and the badge tests
  check the badge text with its leading space.
- **Price history** (3 added): each kind of point drawn with its own marker shape (circle, square,
  up and down triangles), so they differ by more than colour, and a point without coordinates drawn
  as nothing; the chart keeps Recharts' keyboard layer off, as in [8.2](8.2.md); the tooltip shows
  the point's kind, date and price. The existing tests now also check that the chart follows a newly
  added price and that the Price and Source headers mark the active sort. The chart mock records the
  keyboard layer and the number of points, and renders the tooltip once with an empty payload.

## Noticed

- The asset summary labels the price per unit "Current value", next to "Total current value" for
  the holding's worth, while the holdings table uses "Current value" for the holding's worth. The
  tests keep today's labels; renaming it (for example "Current price") is a product change for its
  own PR.
