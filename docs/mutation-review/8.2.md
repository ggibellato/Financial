## Gaps closed (17 test cases)

- **Credits tab** (9):
  - The chart colours: a single credit type is drawn in the single-type blue, several are shaded
    from light to dark blue, and the bars stack together only while Stacked is chosen. The recharts
    mock now records each bar's fill and stack.
  - The line chart's tooltip formats numbers to two decimals, like the bar chart's (one table with
    the existing bar tooltip test).
  - A new credit sends the withheld amount and intermediation fee typed (only the default zeros
    were sent before).
  - Clicking the Type and Value headers marks them as the active sort (added to the existing table
    of headers).
- **Both tabs** (in the counts above, 2 each): the bar and line charts keep Recharts' keyboard layer
  off, so the chart, a named image, holds no focus stop (the rule in
  `docs/ui/forms-data-and-visualisations.md`). The chart mocks now record the setting.
- **Transactions tab** (8): clicking the Type, Quantity, Unit price, Fees, Withheld and Net headers
  marks each as the active sort.
