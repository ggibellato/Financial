# 9.1 Api Program, Middleware and Helpers (71.6% → 90.1%)

Slice notes for [the mutation review](mutation-review.md). The tracker table row and log line
are updated in a separate tracker PR.

| before | after | added | removed | equivalent |
|---|---|---|---|---|
| 71.6% (58 of 81) | 90.1% (73 of 81) | 7 | 0 | 8 |

Files: `Program.cs`, `Middleware/DomainExceptionMappingMiddleware.cs` and `Helpers/`. The middleware
and helpers were already fully covered; every gap was in `Program.cs`'s own wiring, which the
endpoint tests run through but never assert on. Timeouts are counted as detected.

Gaps closed, in the new `ProgramWiringTests` unless stated:

- **CORS**: in Production, a configured origin is allowed, a preflight for it allows the requested
  method and header, and with no configured origins no origin is allowed (Development is not used
  because its appsettings already allow the dev front end).
- **API versioning** reports the supported versions on every response.
- **Options binding**: `Dividends`, `Watchlist` and `AssetPriceFetch` are bound from their
  configuration sections. The feature tests set these options directly, so deleting a
  `Configure<>` line left every test green (found by the simplify review for `Watchlist`).
- **Google Drive file client** is registered.
- **Static files** (`SpaFallbackTests`): a file in the web root is served itself, not the SPA shell.
  `ApiTestFactory` now takes the web root files as one dictionary instead of only `index.html`.
- **Swagger UI** (`SwaggerEndpointsTests`) points at the v1 OpenAPI document with its title.

The 8 still undetected, all reviewed and equivalent:

- **Serilog setup** (3): the configuration read and the log file path; tests do not read log
  files.
- **API versioning** (2): `AssumeDefaultVersionWhenUnspecified` (every route carries the version
  in the URL) and `SubstituteApiVersionInUrl` (the OpenAPI contract test still passes; the document
  transformer sets the server URL).
- **CORS** (2): `Length > 0` vs `>= 0` (an empty origin list allows nothing either way) and removing
  `SetIsOriginAllowed(_ => false)` (an empty default policy allows nothing too).
- **`UseDeveloperExceptionPage`** (1): `WebApplication` adds the developer exception page itself in
  Development, so the explicit call is redundant. Production note, not changed here.
